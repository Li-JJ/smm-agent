# Your First AI Employee: a personal social media agent

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Li-JJ/smm-agent/blob/main/notebooks/workshop.ipynb)


A small, readable agent that learns your writing style, finds topics, drafts posts and comments in your voice,
keeps a human approval step, and learns from your edits and results. LinkedIn first, X supported through config.

## Quick start (Colab)
Open `notebooks/workshop.ipynb` in Google Colab, add `OPENAI_API_KEY` to Colab secrets, and run the cells in order.

## Quick start (laptop)
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
export OPENAI_API_KEY=sk-...      # Windows PowerShell: $env:OPENAI_API_KEY="sk-..."
streamlit run app.py
```

## Your data
Put files in `sources/`:
- LinkedIn export files: `Shares.csv`, `Comments.csv`, `Profile.csv`, `Positions.csv`
- `.txt` or `.md` files with one post per block, blocks separated by a line containing only `---`
  (a file name that contains the word "comment" is treated as comments)

Run the "Learn my style" step again whenever you add files. Duplicates are skipped.

## Layout
| Path | Purpose |
|---|---|
| `agent/config.py` | model name, platform rules, RSS feeds |
| `agent/llm.py` | OpenAI wrappers: chat, JSON chat, embeddings |
| `agent/memory.py` | JSON memory in `data/` |
| `agent/style.py` | ingest files, style profile, example retrieval, word lists |
| `agent/tools.py`, `agent/research.py` | tools and the tool calling loop |
| `agent/generate.py` | post writer with checks and revision |
| `agent/comment.py` | comment options |
| `agent/review.py`, `agent/measure.py` | approvals, feedback, metrics, lessons |
| `app.py` | Streamlit app |
| `sdk_version.py` | same agent with the OpenAI Agents SDK |
| `tests/` | offline tests with a fake client: `python tests/test_offline.py` and `python tests/test_app.py` |
| `docs/diagrams/` | SVG and PNG figures, generated by `docs/make_diagrams.py` |

## Change the model
Set `SMM_MODEL`, or edit `MODEL` in `agent/config.py`. Check the current model list in the OpenAI docs.

## Notes
The agent never posts for you. It drafts, you review, you publish.
